# Loop

`loop.mp4`: 12 s of 1920×1080 H.264 (High, yuv420p, BT.709 limited, 30 fps, ~3.5 Mbps), procedurally rendered (three soft colored lights on closed orbits plus a slow ripple, every term periodic over the 360 frames, so it loops seamlessly) and encoded with Media Foundation's sink writer by a throwaway Rust program.
