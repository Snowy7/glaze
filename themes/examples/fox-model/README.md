# Animated fox

Unmodified [Khronos sample asset](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox).
Model by PixelMannen (2014), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Rigging and animation by tomkranis (2014), and glTF conversion by AsoboStudio
and scurest (2017), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See `UPSTREAM.md` for the upstream attribution record.

Named skeletal clips: `Survey`, `Walk`, `Run`. Select one with the model
layer's `animation` field. A null clip keeps the bind pose and can be baked.
