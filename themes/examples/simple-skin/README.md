# Simple skin

Unmodified [Khronos sample asset](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/SimpleSkin)
by Marco Hutter (2017), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
See `UPSTREAM.md`. Keep the four `.bin` files beside `SimpleSkin.gltf`.

Tiny loader and skeletal animation fixture. Its unnamed clip is exposed as
`Animation 1`. It is intentionally plain, so joint deformation is easy to see.
