# Wallpaper sources and redistribution audit

Research snapshot: **4 November 2026**. This is a content-selection record, not a statement that an uploader owns every image, character, model or soundtrack they used. Assets actually shipped, transformations, licenses, SHA-256 hashes and byte counts are recorded in [CREDITS.md](../../themes/CREDITS.md) and [catalog.json](../../themes/catalog.json). The implementation uses the existing [theme schema](../../crates/theme/src/lib.rs), [shader prelude](../../crates/wallpaper/src/prelude.wgsl) and [local web hosting contract](../web-and-app-wallpapers.md).

## Decision

**Do not bundle Workshop downloads.** Use the Workshop to understand what people like, and offer local owner-controlled importing later. Bundle independently licensed originals instead. Steam grants personal subscription rights; its distribution restrictions and the narrow Wallpaper Engine mobile addendum do not give Glaze a general right to republish subscribed files. An independently licensed original obtained from its rights holder is a separate route. [Steam Subscriber Agreement §§2A, 2G, 6](https://store.steampowered.com/subscriber_agreement/), [Wallpaper Engine Workshop Addendum](https://store.steampowered.com/eula/431960_eula_0), [Wallpaper Engine author-rights reminder](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html).

The revised library contains **15 live themes**, with **eight non-commercial selections clearly named**: three rain variants, three snow selections, and two Seascape palettes. There are no standalone still-image wallpapers in the curated gallery. Their inclusion **blocks distributing this complete library as part of a paid/commercial product** without separate permission. Remove those directories and catalog records or obtain permission before commercial distribution. NC concerns the purpose of use, not simply whether a copy has a price or whether its distributor is a nonprofit. ShareAlike obligations remain on the covered adaptations; the engine does not become CC-licensed merely because it loads separate art files. [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/), [Creative Commons FAQ](https://creativecommons.org/faq/), [individual file credits](../../themes/CREDITS.md).

## Wallpaper Engine / Steam Workshop

### Method and limits

Fetched the current Valve browse pages, preserving their returned order, then fetched **full descriptions and tags for all 57 distinct IDs** using Valve's public `ISteamRemoteStorage/GetPublishedFileDetails/v1/` metadata endpoint. No wallpaper packages, preview images, videos, scene files or application executables were downloaded from Steam. Titles, uploader names and types below come from Valve's responses; an uploader is not necessarily the illustrator or rights holder. Item-page fetches returned HTTP 429, so the public API supplied descriptions instead. [Valve API reference](https://partner.steamgames.com/doc/webapi/ISteamRemoteStorage#GetPublishedFileDetails), [all-time browse](https://steamcommunity.com/workshop/browse/?appid=431960&browsesort=toprated&section=readytouseitems&days=-1&p=1&num_per_page=30), [year browse](https://steamcommunity.com/workshop/browse/?appid=431960&browsesort=trend&section=readytouseitems&days=365&p=1&num_per_page=30).

**Sorting caveat:** the reproducible all-time list here is Steam's `toprated` view, not a claimed lifetime subscriber ranking. The year list uses Steam's **rolling 365-day popular/trend** filter, not calendar-year 2026. `trend&days=-1` did not yield a trustworthy all-time popularity order in the current UI, so it was not substituted silently. Rankings are a dated sample, not permanent “best wallpaper” claims. [Recorded all-time view](https://steamcommunity.com/workshop/browse/?appid=431960&browsesort=toprated&section=readytouseitems&days=-1&p=1&num_per_page=30), [recorded year view](https://steamcommunity.com/workshop/browse/?appid=431960&browsesort=trend&section=readytouseitems&days=365&p=1&num_per_page=30).

### Reuse findings

The only sampled description naming a standard reuse license was **Astesia — Fin de l’Hiver**, by **Immeasurable**: CC BY-NC-SA, without a version number in the statement. It depicts Arknights and therefore does not clear the underlying game IP or music. **Do not bundle it.** Night's custom terms on the Elaina and Subaru items discuss attributed sharing while restricting unauthorized commercial use and cross-platform reposting; they are not an unambiguous license for bundling in another wallpaper app. The Bocchi items explicitly restrict reposting/commercial use. “Free,” “authorized,” and a credit to an illustrator do not grant us redistribution rights. These are findings from the actual descriptions, not assumptions based on their download buttons. [Astesia](https://steamcommunity.com/sharedfiles/filedetails/?id=3668592696), [Elaina](https://steamcommunity.com/sharedfiles/filedetails/?id=3470764447), [Subaru](https://steamcommunity.com/sharedfiles/filedetails/?id=3448290956), [Bocchi](https://steamcommunity.com/sharedfiles/filedetails/?id=3650475846), [Valve metadata API](https://partner.steamgames.com/doc/webapi/ISteamRemoteStorage#GetPublishedFileDetails).

For this library, identified franchise fan art is **excluded unless all relevant rights holders grant the required rights**. This is a curation rule, not a claim that every possible fan work is legally incapable of being licensed. An animator's license cannot clear a third party's character art, music or game assets. Valve itself distinguishes its own fan-art permission from permissions needed for incorporated third-party material. [Steam Subscriber Agreement §2D](https://store.steampowered.com/subscriber_agreement/), [Wallpaper Engine republishing warning](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html).

The Steam UGC grant primarily gives **Valve** rights to operate/promote the service; the Workshop provisions limit subscriber use to the applicable subscription terms. The Wallpaper Engine addendum expressly permits subscriber transfers to compatible **personal mobile devices**, including technical optimization. Neither is a general public redistribution license for glaze. Scene `.pkg` files are Wallpaper Engine formats, while video and web items expose ordinary media/source files; technical accessibility does not change the rights. [Steam §§6A–6B](https://store.steampowered.com/subscriber_agreement/), [addendum](https://store.steampowered.com/eula/431960_eula_0), [Wallpaper Engine file-type explanation](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html).

## Lively Wallpaper

The requested `rocksdanister/lively` repository now redirects to **lively-community/lively**. Its current app license is **GPL-3.0**. This does not mean every bundled wallpaper, photograph, model, soundtrack or gallery submission is GPL. The source tree excludes `Lively/Bundle/`; the build guide instructs builders to supply numbered wallpaper ZIP bundles separately. Consequently this audit does **not claim a complete extraction/audit of the v2.2.1.0 installer bundle**. No installer was executed. [Current repository/license](https://github.com/lively-community/lively/blob/core-separation/LICENSE), [.gitignore](https://github.com/lively-community/lively/blob/core-separation/.gitignore), [building / bundles](https://github.com/lively-community/lively/wiki/Building).

## “Bring your own” importer — design only

This section proposes local behavior; **no importer, downloader, Steam login or external app launcher was implemented**. It targets the files owners already have, preserving credits and provenance without redistributing their library. The supported input formats derive from Wallpaper Engine's own project example and Lively's metadata models; output uses Glaze's existing absolute media paths/local-page host. [Wallpaper Engine project.json example](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html), [LivelyInfoModel](https://github.com/lively-community/lively/blob/core-separation/src/Lively/Lively.Models/LivelyInfoModel.cs), [Glaze web hosting](../web-and-app-wallpapers.md), [Glaze theme schema](../../crates/theme/src/lib.rs).

1. **Choose a local library.** Let the user select a Steam library or Lively folder; optional read-only discovery can inspect Steam's `steamapps/libraryfolders.vdf`. Wallpaper Engine items are `steamapps/workshop/content/431960/<id>/project.json`. Lively commonly uses `%LOCALAPPDATA%\Lively Wallpaper\Library\wallpapers`, or its Microsoft Store package's `LocalCache\Local\Lively Wallpaper` subtree; respect user-configured storage. Show the detected paths and require an item selection. [Wallpaper Engine backup locations](https://help.wallpaperengine.io/en/steam/backup.html), [Lively storage documentation](https://github.com/lively-community/lively/wiki/Getting-Started), [Lively command-line examples](https://github.com/lively-community/lively/wiki/Command-Line-Controls).
2. **Inspect metadata as data.** Read bounded JSON, never execute scripts, executables, shell arguments or install hooks during discovery. From WE retain `title`, `type`, `file`, `preview`, `description`, `workshopid` and the original Workshop link. Canonicalize the selected item's root; reject escaping relative paths and unexpected reparse points. Do not unpack `.pkg` or try to translate the proprietary scene runtime. [WE schema/type explanation](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html).
3. **Map supported types.** A WE `video` maps to `kind: video` with an absolute `source`; a WE `web` maps to `kind: web` with its local entry HTML. Validate extension and decode support, and preserve the whole original web folder for relative scripts/textures. Reject `scene` with an explanation; reject application executables in the initial importer. The current Lively enum has `web=1`, `webaudio=2`, `url=3`, `video=7`, `gif=8`, `picture=11`; version-gate these values rather than guessing future layouts. Use `FileName` plus `IsAbsolutePath` and preserve `Author`, `License`, `Contact`, `Tags`. [WE types](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html), [Lively enum](https://github.com/lively-community/lively/blob/core-separation/src/Lively/Lively.Models/Enums/WallpaperType.cs), [Lively metadata](https://github.com/lively-community/lively/blob/core-separation/src/Lively/Lively.Models/LivelyInfoModel.cs).
4. **Default to a reference, not a copied/re-hosted asset.** Create a small user theme in `%APPDATA%\glaze\themes` with an absolute video/page path and a sidecar origin record. Glaze already maps an external local page's containing directory into its WebView2 virtual host. Never edit the user's Workshop or Lively files. Optional private local copies, if later offered, should remain unexportable until the user supplies actual redistribution rights. [Glaze path rules](../../crates/theme/src/lib.rs), [external local page host behavior](../web-and-app-wallpapers.md).
5. **Explain compatibility before applying.** Ordinary HTML/video can work; Wallpaper Engine audio/property APIs, scene assets, Lively system/weather/audio callbacks and settings UIs are separate contracts. Mark these unsupported until deliberately adapted; do not promise a visualizer works merely because its HTML loads. Start with each item's default properties and muted video. Remote URLs require a separate explicit choice; never automatically navigate during scanning. [WE web properties](https://docs.wallpaperengine.io/en/web/overview.html), [Lively web/system API](https://github.com/lively-community/lively/wiki/Web-Guide-V-:-System-Data), [Glaze limitations](../web-and-app-wallpapers.md).
6. **Keep ownership and failure states visible.** Show “Local import · not included with Glaze,” origin link, author, asserted license (including “unknown”) and missing/unsupported dependencies. If Steam removes/updates a source, retain the record and offer relink/refresh, not a third-party download service. Exclude imported assets from future public theme exports by default. This workflow does not assert that buying a player grants additional copyright or contract rights. [Steam personal-use restrictions](https://store.steampowered.com/subscriber_agreement/), [WE authors' rights reminder](https://help.wallpaperengine.io/en/functionality/editingwallpapers.html).
