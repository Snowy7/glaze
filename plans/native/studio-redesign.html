Design spec · N7

mypaper Studio, redesigned

Studio becomes six places plus Settings: Home, Wallpapers, Look, Widgets, Bars, Integrations. One Look editor replaces the four places that each set part of the look, and holds the five styles and five material controls. Every editing page has the same shape: a live preview drawn by the real renderer, and an inspector that goes presets, the common few, then More. Every old setting has a new place. What the native plan drops is listed separately. Seven decisions are yours; each has a recommendation, so building can start on those.

Decisions for you

DecisionRecommendationThe other way
D1The word "theme"Call the library Wallpapers. A wallpaper can bring a look (a badge on its card), and the word "theme" leaves the UI.Keep "Themes" as the page name.
D2Windows styling becomes yoursStore it in your look, with the wallpaper's own as the layer below. The "Make a copy to edit" dead end goes away. It needs a small schema addition (a user windows section).Keep it in the theme file, and keep Make a copy.
D3Glass in Studio's previewsThe engine draws preview glass offscreen, once per change. A flat stand-in shows while the engine is off. Add Peek (Ctrl D) for a 1:1 check on the real desktop.A CPU stand-in only (no refraction in the preview).
D4Clicking a wallpaper cardClick selects it and shows the details. Use on hover, a double-click or Enter applies it, with Undo.Click applies at once (as today).
D5Integrations as a top-level placeMake it top-level. The research's first batch (media, launcher, notifications, T3 Code, OBS, Docker, Tailscale) plus the built-in plugins fill it.Start it inside Settings.
D6First-run startersFour whole-desktop presets (style, wallpaper, bars, widgets). That's four to curate.A style picker only.
D7Knobs the native material lacksDrop bar saturation, depth, sheen and glass Strength in N6. Strength folds into Refraction and Highlight.Add them to Material.

The shape of it

The places are organized by the thing you change, not by the file it lives in. Search (Ctrl K) reaches every setting, wallpaper, widget, integration and action. Inside a page, you select things instead of switching tabs. The inspector shows what's selected, Esc goes up one level, and advanced settings stay behind More.

Simplified or mergedWhy
Four look editors become one LookN6 makes one token set restyle everything, so one place says so, and "which one wins?" goes away.
Themes become Wallpapers that can bring a lookIt's one object in the files, so it gets one word in the UI. The theme editor becomes Look scoped to that wallpaper.
Windows styling becomes a user layerIt removes the "copy it first" dead end on the theme on screen, the most common case.
Home becomes an overview, not an editorOne editor per thing: Home says what's on and whether it's OK, and links to the editor.
About 40 bar look knobs become Material plus a short per-bar LookNative draws flat fills, edges, shadows and plate glass. Gradients, images, grain and glow are plan losses.
Icon packs move to Look; reduce motion and save power move to SettingsThey now apply to every surface, not just the bars.
The engine and its parts move under TroubleshootSettings no longer opens on internals. GPU and frame rate get their own home.

Look

One editor for everything mypaper draws. The specimen is built from real views: the top bar, the calendar panel, the desktop menu, two widgets and the dock. Material shows only the controls the current style uses.

  • Five style tiles, each drawn in its own style
  • Clarity, Blur, Refraction, Highlight and Tint, while you drag (each drag is one undo step)
  • Scope switch: Your look / the look a wallpaper brings
  • More: text and icons, shape, Different for bars, widgets, menus

  • Updates: Live, or When you open it when live would cost idle CPU
  • Read-only tokens you approve; no borrowed credentials, no injection

Key flows

First run

  1. Pick a starter. It's applied live, and a Peek hint shows.
  2. Your taskbar: replace it, keep Windows' and add widgets, or wallpaper only.
  3. You're set: Start with Windows is on, and the emergency keys are shown. Every step can be skipped and undone.

Switch the wallpaper ("theme")

  1. Home strip (one click), Wallpapers (Use), or Ctrl K then a name.
  2. A toast: "Using Milky Way and its look · Undo".
  3. Your own look choices still win over the wallpaper's.

Change the look

  1. Look, then a style tile: the specimen and the real desktop restyle together.
  2. Drag the material sliders; the preview follows, and each drag is one undo step.
  3. Ctrl D to Peek at the real desktop; ↺ returns to the wallpaper's look.

Arrange widgets

  1. Add widget, then a card: it lands in the first free cell, selected.
  2. Drag to move, or a corner to resize. It snaps, and overlaps are refused.
  3. Its options show in the inspector. Arrange on desktop opens native edit mode.

Set up bars

  1. Pick a preset (macOS, Windows 11…).
  2. Click a bar: design, edge, height. Drag modules, or Add (built-ins, integrations, your own).
  3. The dock: style, size, magnify, pinned apps. Windows taskbar: Hide.

Add a wallpaper

  1. Add wallpaper, then File, Folder, Web page or App.
  2. Details over a live preview: name, fit, arguments, and Performance if you want it.
  3. Add and use, with Undo.

Connect an integration

  1. Integrations, then T3 Code, then Connect: T3 Code approves a read-only token.
  2. Shows in: turn on the top bar module (added to End), notifications and the panel.
  3. Updates reads Live (or When you open it). Disconnect removes what it added, in one undo step.

Troubleshooting and panic

  1. Ctrl Alt Shift Backspace anywhere puts Windows back; Studio says so and offers Start.
  2. A part stopped: the sidebar status links to Troubleshoot, where Restart sits on that part.
  3. A file broke: a banner with Start over (backup kept) and Show file; Studio never rewrites it.

Empty, loading and error states

Errors never rely on color: they use an alert glyph, ink-1 text and a clear action. Destructive actions are undoable instead of confirmed; the only confirmation is Start over, which replaces a file. Loading is rarely seen, because the reads are local. Past 150 ms, static skeletons show, with no shimmer (it would need a gradient).

  • Screen readers: AccessKit from the hits. Segmented controls and tiles are radio groups; sliders report value text ("Blur, 12 pixels"); toasts and the save state are polite live regions. Stage items read as "Weather widget, 3 by 2, column 9, row 1". Every stage action also exists in a list, so nothing needs a pointer.
  • Targets are at least 24×24. Studio follows Windows' Text size setting. With a contrast theme on, tokens map to system colors.
  • Never by color alone: state is a filled dot, a ring, the pause glyph or the alert triangle, always with text.

Removed by the native plan, not by this redesign: theme CSS and the bars' theme variables; gradient, image, grain and glow fills; neon decoration; shaped corners; two of the four Start menu layouts; editing a widget's settings on the widget itself. At risk (D7): bar saturation, glass depth, sheen and glass Strength.

What N7 needs from crates/ui

  • An app-window surface: resizable, with a DWM shadow and snap layouts through WM_NCHITTEST (Studio draws its own caption buttons), at least 960×640.
  • A scroll container, and the controls above built on ops and hits (switch, segmented, slider, select, tiles, sortable list, color field, stepper).
  • Headless previews: the shell's bar, widget, flyout and menu view()s, callable with Studio's model and a scale. The golden-PNG path already proves this works.
  • Preview glass (D3): an engine request to draw these plates over this still, at this size, into shared memory, once per change, freed when Studio closes. Thumbnails are decoded at preview size and released when scrolled away, to stay under 60 MB.

The mockups are static HTML and CSS with no scripts. Wallpaper stills are the themes' own preview.jpg files. Glass in the previews is approximated with CSS; in Studio it comes from the engine (D3). App icons are generic glyphs, not brand marks.
